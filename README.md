# mazmez

משחק אומהה על שלושה לוחות, לשניים עד ארבעה שחקנים אונליין, ומשחק תרגול מול המחשב.

השרת מערבב, מחלק ומחשב את התוצאות. כל שחקן מקבל רק את הקלפים שלו. הטרן, הריבר והקלפים של שאר השחקנים נשלחים רק ברגע החשיפה, כך שאי אפשר להציץ גם עם כלי המפתחים של הדפדפן.

אין צורך להתקין שום חבילה. הפרויקט רץ על Node.js בלבד.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `server.js` | השרת: מגיש את העמוד, מנהל את השולחנות ואת החיבור בזמן אמת |
| `public/index.html` | העמוד והעיצוב |
| `public/app.js` | מה שקורה בדפדפן: ציור המשחק, גרירה, חשיפת הלוחות |
| `public/omaha.js` | חוקי המשחק וחישוב הידיים, משותף לשרת ולדפדפן |
| `render.yaml` | הגדרות מוכנות לאחסון ב-Render |

## להעלות לאינטרנט (פעם אחת, בערך 20 דקות)

### שלב 1: להעלות את הקבצים ל-GitHub
1. נכנסים ל-[github.com](https://github.com) ופותחים חשבון אם אין.
2. לוחצים **New** (מאגר חדש), קוראים לו `mazmez` ולוחצים **Create repository**. אפשר להשאיר אותו פרטי (Private).
3. במסך שנפתח לוחצים על הקישור **uploading an existing file**.
4. פותחים את הקובץ המכווץ, וגוררים לחלון את **כל מה שבתוכו**: הקבצים `server.js`, `package.json`, `render.yaml`, `README.md` ואת התיקייה `public` עצמה (גוררים את התיקייה, לא רק את הקבצים שבתוכה).
5. לפני השמירה בודקים שברשימה מופיעים `public/index.html`, `public/app.js`, `public/omaha.js` ו-`public/icon.svg`.
6. לוחצים **Commit changes**.

### שלב 2: להפעיל את השרת ב-Render
1. נכנסים ל-[render.com](https://render.com) ונרשמים עם חשבון ה-GitHub.
2. לוחצים **New** ואז **Web Service**, ובוחרים את המאגר `mazmez`. אם הוא לא מופיע, מאשרים ל-Render גישה אליו.
3. ממלאים:
   - **Language:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. לוחצים **Deploy**. אחרי כמה דקות מופיעה כתובת כמו `https://mazmez.onrender.com`.

זהו. את הכתובת הזו שולחים לחברים.

## איך משחקים עם חברים
1. אחד פותח את האתר, כותב כינוי ולוחץ **פתיחת שולחן**.
2. הוא לוחץ **העתקת קישור** ושולח את הקישור בוואטסאפ. הקישור כבר כולל את קוד השולחן.
3. החברים פותחים את הקישור, כותבים כינוי ולוחצים **הצטרפות**. אין צורך בחשבון בשום מקום.
4. כשיש 2 עד 4 שחקנים, המארח לוחץ **חלוקה**.

אם מישהו נסגר לו הדפדפן או נפל החיבור, הוא פותח את אותו קישור באותו מכשיר וחוזר בדיוק לאותו מקום, עם אותם קלפים.

## חשוב לדעת על התוכנית החינמית ב-Render
- **השרת נרדם** אחרי כ-15 דקות שאף אחד לא נכנס. בכניסה הבאה לוקח לו בערך חצי דקה עד דקה להתעורר. בתוכנית Starter (כמה דולרים בחודש) הוא לא נרדם.
- **השולחנות והמאזנים נשמרים בזיכרון של השרת.** כשהשרת נרדם או מתעדכן, שולחנות פתוחים נמחקים. בסוף ערב משחק כדאי לצלם את המאזנים.
- המשחק רק סופר את הסכומים. הוא לא מעביר כסף.

## לעדכן את המשחק
מחליפים את הקבצים במאגר ב-GitHub (אותו כפתור **Add file** ואז **Upload files**). Render מזהה את השינוי ומעלה את הגרסה החדשה לבד תוך כמה דקות.

## להריץ על המחשב (לא חובה)
1. מתקינים את [Node.js](https://nodejs.org) (גרסה 18 ומעלה).
2. פותחים טרמינל בתיקייה ומריצים `npm start`.
3. נכנסים ל-`http://localhost:3000`.
